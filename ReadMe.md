# Sonar Rock vs Mine Prediction 🚢💎

This is a **Machine Learning** project that uses a **Logistic Regression** model to predict whether an object detected by SONAR is a **Rock** or a **Naval Mine**.

## 📊 Dataset
The dataset contains 60 frequency patterns obtained from sonar signals. Each pattern is labeled as 'R' (Rock) or 'M' (Mine).

## 🛠️ Technologies Used
* Python
* Pandas & NumPy
* Scikit-learn (Logistic Regression)

## 🚀 How to Run
1. Install requirements: `pip install pandas numpy scikit-learn`
2. Run the script: `python "rock vs mine prediction.py"`
